# Reserve 1.7.3

Account names are easier to set. The Name field in each Claude account's
settings now has a Save button that lights up when you change the name;
Return and leaving the field still save it.

Your original Claude account can now be named too, so it is easy to tell apart
from the accounts you added. Name it "Personal" and it shows as
"Claude · Personal" in Settings, on the dashboard, and in the menu bar. Clear
the name to go back to "Claude". Names you type stay visible when Hide personal
info is on; share cards keep the plain provider name.

Claude status-line forwarding is steadier on a busy Mac: Reserve hands your
original status line its input and reads its output on dedicated threads, so
heavy load elsewhere can no longer make it time out.

1.7.1 and 1.7.2 were tagged but not published; 1.7.3 carries their changes.
