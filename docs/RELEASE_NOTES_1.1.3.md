# Reserve 1.1.3

## Updating from Reserve 0.9.1 or earlier

1. Download Reserve.dmg from this release.
2. Open it and drag Reserve into Applications.
3. Choose Replace, then reopen Reserve.

After this, Reserve can install future updates for you.

## Easier provider connections

- Connect each provider through a guided window with clear progress and recovery steps.
- Open browser sign-in in your regular Chrome session, where your saved passwords are available. If Chrome is not installed, Reserve uses your default browser.
- Verify fresh usage before showing a connection as complete.
- Explain when macOS cannot access or save a sign-in, instead of sending you through the same browser login again.
- Cancel a connection without leaving Reserve waiting for it to finish.
- Keep connection controls usable while usage refreshes in the background.

Your password stays with the provider. Reserve does not save a copy of it.
