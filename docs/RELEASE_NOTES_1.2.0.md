# Reserve 1.2.0

## Updating from Reserve 0.9.1 or earlier

1. Download Reserve.dmg from this release.
2. Open it and drag Reserve into Applications.
3. Choose Replace, then reopen Reserve.

After this, Reserve can install future updates for you.

## Windsurf support

- Add Windsurf as a fifth provider. It starts turned off; connect it in Settings when you want to track it.
- Show cached daily and weekly allowances, reset times, plan name, renewal date, and extra usage balance saved by Devin Desktop or legacy Windsurf.
- Open the desktop app from setup, view your usage settings there, then choose Check again in Reserve.
- Exclude expired allowance windows and keep the last valid snapshot visible when a refresh fails, with a recovery message.
- Scroll to every provider on smaller screens.

Windsurf usage is cached and may lag the website. Reserve labels it as cached and marks old observations as stale. It does not read your protected Windsurf sign-in or request Keychain access.
