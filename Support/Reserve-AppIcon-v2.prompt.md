# Reserve app icon generation prompt

Use case: logo-brand

Asset type: production-ready 1024 x 1024 macOS app icon for Reserve

Input image: the previous Reserve icon is an edit target only for brand context. Preserve only the warm dark palette and the idea of remaining capacity. Remove all skeuomorphic rings, plastic material, bevels, physical gauge details, and provider-colored bands.

Primary request: Create a markedly more modern, minimal, ownable icon for Reserve, a macOS menu-bar app that shows remaining AI subscription capacity and reset windows.

Subject: One bold abstract monogram-symbol combining an uppercase R with a partially open circular capacity meter. The main off-white ring forms the rounded bowl of the R; a precise diagonal cut and stem completes the R. One short coral-orange segment sits in the ring's open gap to signify capacity held in reserve. The symbol must read first as a confident geometric mark, not as a literal gauge.

Style/medium: contemporary flat vector-like identity, 2026 premium software branding, Swiss-geometric restraint, crisp optical geometry, minimal shapes. Extremely subtle depth may come only from a faint tonal background gradient and a restrained inner highlight; otherwise flat.

Composition/framing: centered single glyph, large scale, generous but efficient padding, clear silhouette, perfect optical balance. Rounded-square app tile with macOS-appropriate corner radius. Front-on view.

Color palette: deep warm graphite and cocoa background (`#171210` to `#261B17`), warm ivory symbol (`#F3EEE8`), one restrained coral-orange reserve segment (`#F06A3C`). No blue, green, rainbow, or provider colors.

Constraints: no text beyond the abstract R glyph; no separate letter printed on top; no numbers; no provider logos; no concentric rings; no center dot; no chart; no robot; no brain; no sparkle; no lightning; no battery; no speedometer needle. No thick bevels, rubber, plastic, leather, gloss, stitched detail, or photorealism. It must remain recognizable at 16 px and look native beside modern macOS icons.

Avoid: skeuomorphic control panel, retro dashboard, 3D toy, generic analytics icon, overly thin lines, overly complex negative space, external drop shadow, watermark.
